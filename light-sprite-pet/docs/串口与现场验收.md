# 串口与现场验收

## 串口连接

| USB 转串口 | STM32 |
|---|---|
| TXD | PA10（USART1_RX） |
| RXD | PA9（USART1_TX） |
| GND | GND |

终端设为 115200、8N1、无流控。TX/RX 交叉连接。先只接 GND、TXD、RXD；除非明确核对供电方案，不要把 USB 转串口的 VCC 与开发板电源并接。

## 建议验收顺序

1. 目视检查电源极性、杜邦线插牢、ST-Link SWDIO/SWCLK/GND。
2. Keil 选择 Stage6 编译；确认无报错后下载，复位查看 OLED 启动画面。
3. 按 KEY4 切换表情、状态和诊断页面；按 KEY1/KEY2/KEY3 验证喂食、玩耍和睡眠切换。
4. 转动编码器，确认界面/表情按程序响应；遮挡及照亮光敏模块，发送 `SENSOR STATUS` 对比读数。
5. 发送 `I2C SCAN`、`MPU DIAG`；确认 MPU 地址有应答且静止/转动时数据会变化。
6. 发送 `TAIL CENTER`、`TAIL WAG`、`TAIL SWAY`；确认尾巴运动平顺、机械结构不顶死。舵机务必使用合适的独立 5V 供电并共地。
7. 用 `LED1 ON` / `LED1 OFF`、`LED2 ON` / `LED2 OFF`、`BUZZER TEST` 验证输出，再用 `HELP` 对照完整命令。

## 安全说明

- 上电前检查舵机电源正负；舵机电源 GND、STM32 GND 必须相连。
- 舵机初测时取下负载并观察机械行程，出现抖动、发热或卡阻立即断电。
- OLED 亮起不代表 MPU 通信成功；模块电源灯亮也不代表 I²C 正常。
- 本版本未接入数码管，不能把数码管不亮判为固件故障。
