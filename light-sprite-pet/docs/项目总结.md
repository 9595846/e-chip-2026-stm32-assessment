# 项目总结：光影精灵 STM32 电子宠物

## 项目目标

使用 STM32F103C8T6，将显示、传感器、交互和执行器整合成一个可现场演示的桌面电子宠物。设计过程中，数码管扩展因缺少 74HC595 暂缓，不影响 OLED 主界面和宠物固件运行。

## 完成内容

- OLED 中文页面、表情动画、启动动画和诊断页。
- 按键消抖与旋钮编码器输入。
- 光照模拟量采样，MPU6050 六轴数据读取及状态检测。
- USART 命令接收与状态反馈。
- LED、低电平触发蜂鸣器和舵机尾巴控制。
- 舵机限角与独立 5V 供电、STM32 共地的硬件方案。
- Stage1 到 Stage6 分阶段 Keil 工程配置及最终 HEX。

## 个人能力体现

- **需求分析：**把功能要求拆分为输入、显示、传感、执行、通讯等模块，并识别硬件资源限制。
- **嵌入式开发：**使用 STM32 标准外设库配置 GPIO、ADC、定时器 PWM、USART 与 I²C/软件 I²C。
- **系统集成：**处理 OLED 与 MPU6050 总线分配、SWD 保留、串口交叉连接和舵机独立供电共地。
- **调试排障：**利用串口诊断、I²C 地址扫描和传感器状态页，逐步排查无显示、无应答及执行器问题。
- **工程交付：**整理 Keil 工程、HEX、接线资料、编译记录、操作说明和验收边界。

## 验证边界

随项目保留的 Stage6 Keil 记录显示编译、链接成功，0 error、0 warning。实体运行情况依据项目使用者反馈；本报告不宣称在本次整理过程中重新进行了板级复测。数码管 5461BS-1 及 74HC595 不在当前已接入功能范围。

## 可继续改进

1. 增加 74HC595 与合适限流电阻后，启用数码管并验证动态扫描亮度与刷新率。
2. 将串口协议、按键交互和传感器状态整理成自动化测试用例。
3. 对光照阈值、MPU 姿态阈值和尾巴动作参数做多轮实测标定。
4. 补充实体装配照片、演示视频和现场验收记录。
